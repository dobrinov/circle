The arc, completed.

Circle is a calm, sidebar-first browser built on Chromium and written in Rust. Your tabs live in a sidebar, organised into spaces, with everything else one keystroke away.

Download Circle View on GitHub

Free and open source · macOS, Windows and Linux

Features

Everything in its place.

Spotlight, for tabs and the web

Press ⌘ K and start typing. Jump to an open tab in any space, open a site in a new tab, search the web, or find that page from yesterday in your history.

Split view, side by side or stacked

Read the docs next to the thing you're building. Split with ⌘ ⇧ = or a tab's right-click menu, and stack the pages with ⌘ ⇧ -.

Light, dark, or your system's

Circle follows your system or stays light or dark, and websites that support dark mode switch with it.

For developers

Built for people who build the web.

DevTools, docked where you want them

Chrome's developer tools, docked to the right, the bottom or in their own window. Drag the edge to resize. ⌥ ⌘ I or right-click › Inspect Element.

Your dev server, clearly marked

Tabs on localhost get a DEV badge and the address bar shows the port, so you never confuse your local build with production. On macOS the page frame picks up soft stripes too.

Record the page as a video or GIF

Press ⌥ ⌘ R, pick Video or GIF and press Start. Show the bug or the feature, press Stop, and the file lands in your Downloads.

Spaces with their own colour

Keep work, side projects and reading apart, each with its own pinned tabs and colour.

Folders and renaming

Group pinned tabs into folders and give any tab a name that sticks.

History you control

Search everything you've visited, remove single pages or clear a time range.

Quiet window chrome

An even frame around rounded pages; the sidebar slides away and peeks back from the edge.

Downloads at hand

Downloads and recordings in a panel at the bottom of the sidebar, with closed tabs a click away.

Bug reports that write themselves

Describe the problem, reproduce it, and get a GitHub issue with a timeline and page errors.

Settings in one place

Theme, search engine, tab archiving, site permissions and more, at ⌘ ,.

AI agents

A browser your agent can drive.

Circle ships an MCP server, so agents like Claude Code can open tabs, read pages, click and type in your real browser. It's off until you allow it, the sidebar shows when an agent is in control, and one click stops it.

# macOS
claude mcp add circle -- /Applications/Circle.app/Contents/MacOS/circle-mcp

# Linux (.deb)
claude mcp add circle -- /opt/circle/circle-mcp

# then, in Circle's command bar: Allow Agent Control
